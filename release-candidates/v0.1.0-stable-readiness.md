## Approved Post-Release Rollback Plan

Before release, rollback means no external action: retain `v0.1.0-rc.1` and do
not create stable `v0.1.0`.

After the approved stable publication, the approved rollback is to delete only
the GitHub release `v0.1.0` and its `v0.1.0` tag, then verify that
`v0.1.0-rc.1` remains unchanged. No registry package, deployment, database, or
active-global configuration write is part of the stable publication itself.
This plan was approved together with the exact stable external action on
2026-08-12. Executing it remains a separate destructive external action and
still requires fresh explicit user approval.
